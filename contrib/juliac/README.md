# juliac

The `juliac` driver for compiling Julia code to executables, shared libraries,
and system images (with optional trimming) can be found at
[JuliaC.jl](https://github.com/JuliaLang/JuliaC.jl).  See that repository for
usage and CLI options.

`test/trimming/juliac-buildscript.jl` is for Julia's own `--trim` tests.
